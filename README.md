# tiny-chess

Tiny 4 KiB Python chess engine for make.fun tiny-chess-01.
Main file: main.py (packed zlib payload, <=4096 bytes as committed; Python 3.13, stdlib only).
Ideas credited to the public 4 KB engine literature; engine source is original.

Run: python3 main.py (it enters the make.fun gauntlet via MAKEFUN_ENV_URL).
